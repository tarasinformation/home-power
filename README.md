# Світло вдома

Монітор світла для квартири чи будинку: плата ESP32 за ~100 грн показує на вашому телефоні, чи є вдома електрика, з якого часу її немає, офіційний графік відключень поруч із тим, що було насправді, і заряд зарядної станції EcoFlow.

*[English version](README.en.md)*

## Як це працює

```
резервне живлення                         звичайна розетка
  ├─ роутер                                 └─ індикатор: будь-яка техніка з Wi-Fi
  └─ плата ESP32-C3 ── ping кожні 20 с ──▶     (бойлер, підсилювач Wi-Fi…)
        │  ╲
        │   ╲ Bluetooth: заряд EcoFlow (необов'язково)
        │ HTTPS, ключ плати
        ▼
  Convex: прийом сигналу ─▶ база ◀─ розклад: «плата замовкла?», графік Yasno
        ▲
        │ живе оновлення, лише після входу
  сайт (Vercel) ◀── телефон
```

- **Індикатор.** Пристрій із Wi-Fi у розетці без резерву. Відповідає на ping – світло є; два цикли поспіль мовчить – світла немає.
- **Плата** стоїть на резервному живленні разом із роутером. Звіт надсилає раз на хвилину і одразу, щойно щось змінилося. Початок відключення записується часом першого невдалого ping.
- **EcoFlow** (перевірено на DELTA 2 Max) сама транслює свій заряд у Bluetooth-оголошенні. Плата просто його слухає: без облікового запису й без підключення до станції.
- **Споживання.** Процесор плати працює на 80 МГц замість 160. Bluetooth запускається, лише коли задано станцію, і слухає її раз на хвилину – до першого почутого оголошення, не довше 4 секунд.
- **Немає зв'язку з домом.** Якщо плата мовчить понад 5 хвилин, сторінка показує «Немає зв'язку з домом» (зник інтернет або резервне живлення).
- **Офіційний графік** береться з відкритого API Yasno (Київ, ДТЕК Київські електромережі) кожні 20 хвилин і зберігається по днях, тож видно, де графік і реальність розійшлися.

## Що на сторінці

- Статус «Світло є / Світла немає / Немає зв'язку з домом», з якого часу, плашка з графіка («є світло до 18:00») і попередження, якщо факт розходиться з графіком.
- Зарядна станція: відсоток, напрямок і прогноз «вистачить на ≈ …» або «повна через ≈ …».
- День по годинах у стилі графіків «Київ Цифровий»: минулі години – як було насправді, майбутні – за графіком; натискання на годину показує подробиці.
- Заряд станції за добу, тиждень рядками, список відключень.
- Необов'язково: температура й вологість вдома з графіком за добу, на якому видно, як дім холоне без світла. Картка з'являється, коли окрема плата починає надсилати покази на `POST /home` (ключ у змінній `HOME_TOKEN`, формат описано в `web/convex/http.ts`); прошивка такої плати на ESP32-C6, з оновленням по Wi-Fi, лежить у [hub-reader/](hub-reader/README.md).
- Погода надворі на тому самому графіку та поточні умови (температура, «відчувається як», вітер, вологість, опади): відкритий API [Open-Meteo](https://open-meteo.com/) без ключа, опитується раз на 15 хвилин. Місце задають змінні `WEATHER_LAT`, `WEATHER_LON` і `WEATHER_PLACE` (за замовчуванням центр Києва); `WEATHER_LAT=off` вимикає.
- Світла й темна теми, мобільний інтерфейс, анімації (вимикаються налаштуванням «зменшити рух»).

## Що в репозиторії

| Шлях | Що це |
|---|---|
| `firmware/` | Прошивка ESP32-C3 (PlatformIO, Arduino), `make_secrets.py`, що створює `include/secrets.h`, і `ota_upload.py` для оновлення по Wi-Fi |
| `hub-reader/` | Необов'язкова друга плата (ESP32-C6, ESP-IDF + esp-matter): читає температуру й вологість із хаба розумного дому через Matter і шле на сайт. Докладно: [hub-reader/README.md](hub-reader/README.md) |
| `web/convex/` | Бекенд Convex: прийом сигналу (`http.ts`), стан і журнал (`power.ts`), графік Yasno (`schedule.ts`), розклад (`crons.ts`), вхід (`auth.ts`) |
| `web/convex/lib/logic.ts` | Уся логіка станів без залежностей від Convex: її використовують і сервер, і сторінка |
| `web/convex/home.ts`, `web/convex/weather.ts`, `web/convex/lib/home.ts` | Клімат вдома й погода надворі: прийом показів, опитування Open-Meteo та логіка графіка |
| `web/src/` | Сайт: Vite + React + TypeScript |
| `web/dev/` | Сторінка на вигаданих даних, без входу й бекенда: `npm run dev`, потім `/dev/preview.html`. У зібраний сайт не потрапляє |
| `web/tests/` | Тести логіки: `npm test` |
| `web/scripts/` | Розгортання, ключі входу, пошук черги Yasno за адресою |

## Залізо

- ESP32-C3 Super Mini (або інша ESP32 з Wi-Fi і Bluetooth), живлення USB від резерву.
- Індикатор у розетці без резерву, що відповідає на ping. Закріпіть за ним адресу на роутері (статична DHCP-ліза).
- Необов'язково: зарядна станція EcoFlow поруч із платою.

## Корпус

Готова модель Jeroen van Grondelle: [GitHub](https://github.com/jeroenvangrondelle/esp32-super-mini-case) або [Printables](https://www.printables.com/model/1137008-esp32-c3-super-mini-case). Число в назві файлу – довжина плати без роз'єму: для ESP32-C3 Super Mini на 25 мм підходить `stl/26mm-case.stl` (запас близько 1 мм). У файлі шість деталей на одному столі; у слайсері розділіть модель на частини (у Bambu Studio: «Split to objects») і надрукуйте низький корпус 8,5 мм та одну з кришок, суцільну чи з сіткою. Підтримки не потрібні.

## Розгортання

Потрібні Node.js, обліковий запис [Convex](https://convex.dev) і [Vercel](https://vercel.com); безкоштовних тарифів досить. Усі команди – у папці `web/`.

1. Залежності: `npm install`.
2. Проєкт Convex: `npx convex dev --once` (створить проєкт і запише адресу в `.env.local`), потім `npm run deploy`.
3. Ключі входу: `node scripts/auth-keys.mjs`, адреса сайту: `npx convex env set --prod SITE_URL https://ваш-сайт`.
4. Ключ плати одразу у зв'язку ключів macOS і в Convex, не показуючи на екрані:
   ```bash
   security add-generic-password -a "$USER" -s home-power-device-token -w "$(openssl rand -hex 32)"
   security find-generic-password -s home-power-device-token -w | tr -d '\n' | npx convex env set --prod DEVICE_TOKEN
   ```
5. Офіційний графік (Київ): `node scripts/yasno-group.mjs "вулиця" "будинок"` покаже чергу, потім `npx convex env set --prod YASNO_GROUP 3.1`. Інший регіон: змінні `YASNO_REGION` і `YASNO_DSO`.
6. Сайт: `npx vercel link`, `npx vercel env add VITE_CONVEX_URL production` (адреса `https://<назва>.convex.cloud`), `npx vercel --prod`.
7. Обліковий запис: `npx convex env set --prod ALLOWED_EMAILS ваша@пошта`, зареєструйтеся на сайті, потім `npx convex env remove --prod ALLOWED_EMAILS`. Без цієї змінної ніхто не зареєструється; пошта не підтверджується листом, тож не тримайте її довше, ніж треба.
8. Прошивка: у `firmware/` запустіть `python3 make_secrets.py https://<назва>.convex.site` (запитає Wi-Fi, адресу індикатора й номер станції), потім `pio run -t upload` (кабелем). Наступні версії можна надсилати [по Wi-Fi](#оновлення-по-wi-fi).

## Оновлення по Wi-Fi

Перший раз прошивку з підтримкою оновлення (версія 0.6 і новіші) записують кабелем: `pio run -t upload`. Далі кабель не потрібен. У папці `firmware/`:

```bash
pio run && python3 ota_upload.py <адреса-плати>
```

- **Пароль оновлення** створює `make_secrets.py` і кладе у зв'язку ключів macOS; у `secrets.h` потрапляє його SHA-256. Якщо `secrets.h` уже є, досить `python3 make_secrets.py --ota-only`: решта файлу не змінюється. Без рядка `OTA_PASSWORD_SHA256` прошивка збирається без оновлення по Wi-Fi.
- **Адресу плати** скрипт бере з аргументу або змінної середовища `BOARD_IP`; у репозиторії її немає. Пароль він читає зі зв'язки ключів сам, на екрані й у командному рядку пароля немає.
- **Відкат.** Нова прошивка має за 5 хвилин підключитися до Wi-Fi й надіслати звіт (або хоча б лишитися досяжною в мережі). Не вийшла на зв'язок, зависла чи перезавантажилася до цього – плата сама повертає попередню. Зникло живлення в ці хвилини – теж відкат, оновлення треба повторити. Поки нову прошивку не підтверджено, наступне оновлення плата не приймає.
- **Перевірка.** Наприкінці скрипт питає плату (UDP 3233: версія, мітка збірки, стан, час роботи й температура кристала – без секретів), яка збірка працює, і пише «Готово» лише тоді, коли це надіслана збірка і плата її підтвердила.

## Безпека

- Плата пише лише в `/report` з ключем; ключ порівнюється способом, стійким до атак за часом.
- Дані віддають тільки запити Convex після входу. Сайт на Vercel – статичні файли без даних.
- `secrets.h`, `.env.local` і прив'язки Vercel/Convex у `.gitignore`.
- Оновлення по Wi-Fi захищене паролем, але ключем є саме SHA-256 пароля із `secrets.h`: хто має цей хеш або зібраний `firmware.bin`, той може оновити плату. Образ містить ще пароль Wi-Fi і ключ плати й передається локальною мережею відкрито. Захист розрахований на домашню мережу без сторонніх пристроїв; `secrets.h` і папку `.pio/` нікуди не копіюйте.

## Безкоштовні тарифи

Монітор розрахований не виходити за безкоштовний Convex (1 млн викликів на місяць): звіт раз на хвилину й лише при змінах, розклад раз на 5 хвилин, графік раз на 20 хвилин, історія чиститься щодня. Разом близько 100 тис. викликів на місяць; відкрита сторінка додає до 45 тис.

## Обмеження

- API Yasno недокументований і може змінитися; при збої лишається останній відомий графік.
- Розбір Bluetooth-оголошення EcoFlow перевірено лише на DELTA 2 Max.
- Індикатор – один пристрій: якщо в нього збій Wi-Fi, сторінка покаже це як відключення.
